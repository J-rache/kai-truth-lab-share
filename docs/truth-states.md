# Truth States

Truth states are the core contract of the lab.

| State | Meaning | Evidence Needed |
| --- | --- | --- |
| `hypothesis` | An idea that might be useful. | None |
| `design_sketch` | A possible design shape. | None |
| `unverified` | A claim made before proof. | None |
| `machine_proven` | A machine check passed. | A command, run id, artifact, or log |
| `source_backed` | A claim backed by a source reference. | Source URL, file path, citation, or note |
| `production_ready` | Ready to depend on. | Machine evidence plus source or review evidence |

The lab lets imagination exist. It only blocks the moment a speculative claim tries to dress itself as proven.
