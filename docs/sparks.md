# Sparks Found During Build

These were the extra ideas that appeared while building the v1 scope.

## Implemented Now

- Add a dashboard so humans can use the lab without memorizing CLI calls.
- Add an MCP server because some tools should be model-facing instead of human-facing.
- Add a public export script so the internal repo can stay private while a clean shareable repo can exist.
- Add a local Windows launcher so the lab behaves like a standalone app.
- Add a secret scan because truth work should fail before accidental credential publishing.
- Add a markdown link check because docs should not claim paths that do not exist.
- Add a TODO completion check so the "everything I want" list itself becomes verifiable.
- Add an autonomy cycle and scheduled task so the lab can check itself without waiting for a human.
- Add a failure inbox so broken checks become durable work.
- Add Mystro handoff and tool-promotion decisions because those are operational decisions, not docs.
- Add proof bundles because final answers should have a durable artifact behind the claim.
- Add repository redundancy tracking because GitHub and GitLab destinations should be explicit and separately verified.
- Add next-work decisions because autonomous choice should leave an audit trail.

## Future, Not Claimed Complete

- Native packaged desktop app.
- Real remote multi-user auth.
- Rich historical charts.
- Deeper benchmark suites for multiple model families.
- Direct Mystro Table plugin package beyond the current HTTP handoff.
- Optional cloud database adapter inside the public project.

Those future items are not part of this completed v1. They are recorded so they do not become hidden promises.
