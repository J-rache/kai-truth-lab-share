# Model Client MCP Example

Use `client-packages/mcp/codex-truth-lab.local.json` as the local MCP config.

Model-facing tools:

- `truth_lab.status`
- `truth_lab.list_evals`
- `truth_lab.run_eval`
- `truth_lab.source_status`
- `truth_lab.add_claim`
- `truth_lab.add_tool`
- `truth_lab.write_note`

This is for model clients. Human operators can use the dashboard or CLI.
